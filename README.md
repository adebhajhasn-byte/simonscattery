# Simons Cattery

موقع مربّى Maine Coon — صفحات HTML ساكنة تنبنى من ملفات المحتوى.

```
├── content/          ← المحتوى (اللي بتعدّلو اللوحة)
│   ├── cats/         ← ملف لكل قطة
│   ├── posts/        ← ملف لكل مقالة
│   └── pages/        ← الصفحات وبيانات التواصل
├── scripts/build.js  ← بيبني الموقع من content/
├── site/             ← الناتج (Netlify بتنشر من هون)
│   ├── images/       ← الصور والفيديو
│   └── admin/        ← لوحة التحكم
├── netlify.toml
└── package.json
```

## كيف بيشتغل

```
content/*.json  ──►  npm run build  ──►  site/*.html
```

الزبونة بتعدّل من `/admin` → بينحفظ على GitHub → Netlify بتعيد البناء لحالها.

**ولا داتابيس، ولا سيرفر، ولا اشتراك.**

## أوامر

| | |
|---|---|
| `npm run build` | يبني الموقع |
| `npm run serve` | يبني ويفتح على localhost:8000 |

## الملفات

- **SETUP.md** ← دليل الرفع (اقرأه أول)
- **FOR-THE-OWNER.md** ← دليل الزبونة (إنكليزي — ابعتلها إياه)

## شو انعمل

**حذف:** `Simons Life´s Dream` من Kings · كرت `Pownee's Princess` من Queens (صفحتها ضلّت) · `Welfare / tips` من المنيو.

**إضافة:** `Simons Nefertiti` · `CH Simons My P Prince` · `Simons Harriette` (مع فيديو، حوّلناه من 78MB لـ 7MB).

**ميزة جديدة:** قسم **البطولات** بصفحة كل قطة — بتشتغل من اللوحة: مفتاح تشغيل، قائمة بالألقاب، وصور من العروض. القطط اللي ما عندها بطولات ما بيظهرلها شي.

**تصحيحات:** عدّاد Kings كان 5 صار 4 · أسامي الأهل صاروا روابط · تصليح ترميز بخانات alt.

**تنظيف:** الصور من 312 ملف (59MB) لـ 108 (26MB) — نسخ مكررة خلّفها الووردبريس.
